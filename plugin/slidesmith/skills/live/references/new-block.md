# 再加一种玩法（给下一个会话看的）

## 一个「互动块」长什么样

```
assets/blocks/<key>/
  slide.html    要插进 deck 的那一页（一个 <section class="slide …">，用占位符 __SEG__/__SEGNAME__）
  block.html    <style> + <script>，注入到最后一个 </body> 之前
  student.html  学生扫的那页（只有中转不提供现成页时才需要，见下）
  README.md     这个块要什么房间号 / 用哪些消息 / 有什么坑
```

`inject-live.mjs` 认这个结构，`--blocks a,b` 就能同时装多个。加块**不用改注入器**。

## ⚠️ 动手前先知道这一条

「新玩法只要写两页、中转一行都不用改」——**这句话只在你复用 `qa-*` 消息时成立**。

`smrelay.py` 的 `on_message()` 是**类型白名单**：`ask` 角色只认 `qa-add`，
`host`/`wall` 只认 `qa-clear / qa-hide / qa-scroll / qa-close / qa-open`。
自己编一个 `{type:"vote"}` 发过去，服务端**默默丢掉**，两头都不报错，
表现是「学生点了没反应」，很能耗掉一小时。

而且学生那页 `/q/<房间>` 是中转写死的提问页（`ask.html`），换不了。

于是只有两条路：

### 路线 A · 不碰服务端（搭 qa 的便车）

把结构编进 `qa-add` 的 `text` 里，wall 端自己解析：

```
学生点了 B  →  {type:"qa-add", text:"#vote:B"}
大屏 wall   →  收到 qa-new，看见 /^#vote:(\w+)$/ 就计票，不当问题显示
```

- ✅ 零风险、今天就能做；条目自动进账本，事后 CSV 里看得到
- ⚠️ 会混进问答导出（约定所有非提问都以 `#` 开头，导出后一眼能筛）
- ⚠️ 吃 qa 的阀门：**同一台设备两次提交间隔 ≥4 秒**、单条 ≤200 字（投票够用，抢答不够）
- ⚠️ 服务端不做聚合：每块大屏各算各的票；中途打开的大屏靠 `qa-init` 的全量补齐，能对上
- ⚠️ 学生页得自己写一页（`/q/` 那页是提问框），托在 **myspace** 上给个短链
  —— 中转 CORS 是 `*`、WS 不校验 Origin，跨域连得上。**别用 `*.workers.dev` 托**

### 路线 B · 改服务端（一次性做通用通道）

给 `smrelay.py` 加一个通用类型（`item` 表里 `kind` 字段**早就留好了**，现在恒为 `'q'`）：

```
学生 → {type:"live-post", kind:"vote", v:"B"}     服务端按 kind 落盘 + 广播给 wall/host
中转   /q/<房间>?mode=vote  按 mode 发不同的学生页
管理台 按 kind 分开显示与导出
```

- ✅ 干净、可扩展、账本天然分类
- ⚠️ 要改代码 + 重新部署 + 跑 `scripts/verify-live-service.mjs`，还要保证**老 deck 一个字不改照常能用**

**建议**：第二种玩法先走 A 试水（一场课就知道值不值得做）；要上到三种以上，再一次性做 B。

## 写块时的检查清单

- [ ] 角色用 `wall`（只收），**不是** `deck`
- [ ] 一律 `document.querySelector('#deck …')`，别用 `getElementById`
      —— 引擎把每页克隆进左侧缩略图，id 在文档里有两份，拿到的是缩略图那个克隆
- [ ] 颜色全走令牌（`--paper/--ink/--rule/--accent/--font-*`），22 张皮通用；
      **只有二维码底写死白色**（深色皮上黑底二维码扫不出来）
- [ ] `data-seg` **必须是数字**（引擎 `segOf()` 是 `parseInt`；写字母会得到 `sNaN-1`，段导航里也没这一页）
- [ ] 要滚的区域用 **grid**，**不能 `column-count`**（多栏在固定高度里往右开新栏，纵向永远滚不动）
- [ ] 运行时才出现的文字（学生输入）显式用系统字体栈 —— 它不可能进字体子集，
      否则一行里认识的字用内嵌字体、不认识的掉回 fallback，同一句两种字形
- [ ] 连不上要**优雅退化**成静态二维码（学生照样能提交，只是不上大屏）
- [ ] 别截断内容。截断＝把最早参与的那几个人无声删掉，而现场往往正是从最早那几条开始
- [ ] 读引擎算出来的值（`SLIDE_MAP`、`--fit-scale`）**不能赌时机** —— 隔几拍补算
- [ ] 装完跑 `node scripts/verify-live-inject.mjs`，并给块补一条真浏览器断言
