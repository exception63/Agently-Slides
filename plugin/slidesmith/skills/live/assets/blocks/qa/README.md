# 互动块 qa —— 扫码匿名提问 · 实时上墙

**状态**：已上线，2026-08-28 现场实战跑过（企业管理硕士培养方案宣讲，三端联调 12/12）。

| | |
|---|---|
| 学生页 | 中转自带 `/q/<房间>`，不用自己写 |
| 大屏 | `slide.html`（一页）+ `block.html`（CSS/JS） |
| 角色 | `wall`（只收、多实例共存） |
| 消息 | `qa-init` / `qa-new` / `qa-cleared` / `qa-hidden` / `qa-scroll` |
| 要的全局 | `__SM_QA_ROOM__` · `__SM_CLOUD_RELAY__`（`inject-live.mjs` 自动写） |
| 依赖 | `vendor-qrcode.js`（注入器自动带；已在就跳过） |

## 现场怎么控

在 iPad 上开 `https://live.zhouliying.com/r/<房间>`：清屏 · 隐藏某条 ·
关闭/重开提问 · **大屏 ⬆⬇**（翻大屏上的问题墙，不用去碰讲台电脑）。
懒得掏 iPad 就用管理台，同样能远程清屏 / 关提问。

## 大屏这一页上还能放别的二维码

页面里任何 `<div class="qrbox" data-qr="https://…"></div>` 都会被自动画成二维码
（讲义、方案、课件链接）。`.qrbox--lg` 是大号。

## 已知取舍

- **不截断**：全部保留 + 墙可滚 + iPad 能翻。1920×1080 三栏一屏约 21 条。
- 问题卡的正文走**系统字体栈**（运行时文字进不了字体子集）。
- 连不上 → 状态点变红、退化成静态二维码，学生照样能提交，讲者在 iPad 上看。
